# UE 表现层

本目录不参与 CMake 构建。UE 工程、引擎本体与插件二进制均不入库。

## 前置

1. 核心层已构建出静态库：`build/core/velnoria_core.lib`（MSVC）或 `libvelnoria_core.a`
2. 设置了 `VELNORIA_CORE_ROOT`（默认回退到本仓库 `core/`）
3. 引擎版本锁定在 `.uplugin` 中声明的 5.6.0，不做跨小版本兼容

`Build.cs` 找不到静态库时会直接抛异常，不静默降级。

## 边界

插件只做三件事：

| 允许 | 说明 |
|---|---|
| 读快照 | `ChunkSnapshotPtr` 不可变，按 `generation`/`tick` 丢弃过期 |
| 网格化 | 工作线程执行，结果投递回游戏线程 |
| 提交渲染 | 材质、光照、后处理、相机、HUD、音频 |

禁止：在插件内实现任何游戏规则（移动判定、伤害、方块更新顺序）。出现这类代码即视为架构违规，需在 review 中拒绝。
